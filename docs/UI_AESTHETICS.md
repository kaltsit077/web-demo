## 本轮落地规则

| 原则 | 做法 |
|------|------|
| 间距节奏 | 组内 8–16、区块 24–32、页面边距 32 |
| 亲密性 | 主按钮与次按钮拉开；标题与副文靠近 |
| 对比 | 「开始游戏」最大最亮；次级 ghost |
| 对齐 | 导航左缘统一；面板内容同起点 |
| 层级 | 品牌 > 主 CTA > 次导航 > 免责声明 |
| 克制 | 减少满屏青光，装饰集中在 hero 印章 |
| 重复 | 所有屏共用同一页眉 chrome + 返回位 |
