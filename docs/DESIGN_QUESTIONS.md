## 核心玩法定稿

### 1. 核心循环

```
选关 → 选取出战角色 → 波次开始
  → 自动上弓当前角色（可换人）
  → 拉方向 + 辅助线 → 发射（= 推进 1 回合）
  → 命中结算伤害；试卷每 5 秒降 1 格（与发射解耦）
  → 越墙扣血 / 3 球越线 → 失败
  → 本波清空 → 三选一 Buff（Phase 1 可 stub）
  → 全部波次完成 → 结算 → 重试 / 下一关 / 返回
```

**节奏**：无限弹药 · 塔防压迫 · 后期靠规则 + 上方压力多线思考。

### 2. 胜负

| 项 | 规则 |
|----|------|
| **击溃** | 累计伤害 ≥ 试卷**合格线** → 试卷消失 |
| **加分** | 超出合格线的伤害 → **额外分数**；默认满分 100，初中卷可 120，高中卷可 150（按试卷 Setting 配置 `maxScore`） |
| **胜利** | **纯波次**：Setting 内所有波次出完且场上试卷全部击溃 |
| **失败** | 玩家固定 HP；**3 个试卷越过墙体** → 游戏结束；单个试卷越墙 → 扣血（不算击溃） |
| **过关后** | 结算前：从未解锁干员中**随机三选一解锁**（每课首次通关一次，写入存档）→ 结算面板：积分 / 重试 / 下一关 / 返回 |
| **失败后** | Phase 1：**重试 + 返回选关**；**不做**续关 |

### 3. 波次

- **纯波次**，无随机增援。
- 每波结束：**三选一 Buff**（Phase 1 预留 UI + 数据钩子，可只实现 1 个占位 Buff）。
- 胜利闭包：`所有波次已触发 && 场上无存活试卷`。

### 4. 试卷（原「球 / 目标」）

- 术语统一：**试卷** = 场上目标；**干员** = 弹射角色。
- 种类（愿景）：单词默写-en1、默写-语文1、计算题-数学1、模拟考、周测、月考……
- 大关卡阶段：小学部 → 初中部 → 高中部。
- 行为：按关卡配置；Phase 1 试卷按**时间**下落——每 **5 秒**下降 **1 格**（不因发射推进）。
- 出界：不算击溃，扣玩家 HP。

**试卷数值字段（Setting + 运行时）**

| 字段 | 说明 |
|------|------|
| `passLine` | 合格线（击溃阈值） |
| `maxScore` | 满分上限（默认 100；初中 120；高中 150） |
| `hp` / 当前累计伤害 | 运行时追踪 |
| `radius` | 碰撞半径 |
| `subject` | 学科：`chinese` / `math` / `english` / … |
| `resistance` | 学科抗性（按类型配置） |
| `tag` | 普通 / 精英 / boss |
| `moveRule` | 每回合下落格数与方向 |
| `gridPos` | 格子坐标（运行时；首版格子制） |

### 5. 干员（弹药 / 角色）

- 每关可选 N 名出战；候选区随机刷新；**每发射 1 回合补充 1 人**。
- **自动上弓**队首（或当前选中）角色；**可手动换人**再上弓。
- 学科属性（语/数/英）→ 对同学科试卷算伤害；属性为 0 → 无实际伤害（道具固伤除外）。
- 排队形态 / 上弓形态：**美术资源区分**；玩法上可换人与上弓前操作（Phase 1 换人即可）。

**伤害公式（定稿方向）**

```
baseDamage = 角色对应学科值 × 克制系数(角色, 试卷)
finalDamage = (baseDamage + flatBonus) × buffMultiplier
```

- 道具 / Buff 走独立乘区或加区；Phase 1 仅实现 base + 克制，其余走 `modifiers` 钩子。

### 6. 弹弓操作

| 项 | 定稿 |
|----|------|
| 拉力 | **只改方向**，速度固定 |
| 重力 | **无**（直线弹道） |
| 辅助线 | **要** |
| 输入 | PC 鼠标优先；预留触屏 + 键盘（答题） |

### 7. 特殊机制（正文定稿 · Phase 1 预留）

#### 7.1 人物 / 学科克制

- 每人有语/数/英基础数值。
- 用对应能力打试卷；数值 0 → 0 伤；道具固伤另算。

#### 7.2 道具（上弓后、发射前可用 · Phase 1 预留）

| 类型 | 行为 |
|------|------|
| 固定伤害 | 无视学科追加伤害 |
| 溅射 | 命中点周围试卷受伤 |
| 持续伤害 | 命中试卷每行动一次扣固定值 |
| 二次弹射 | 命中后弹向下一目标 |
| 替身使者 | 借用另一角色的某一学科值，保留当前角色机制 |

#### 7.3 规则怪谈（Phase 1 预留）

**负面示例**

| 规则 | 行为 |
|------|------|
| 她笑起来准没好事 | W 处于笑脸形态时发射 → 自爆扣 1 HP + 额外推进 1 回合 |
| 强迫症 | 某角色奇数回合不可发射 |
| 文盲 | 对语文卷伤害减半；答题时一半文字变「口」 |

**增益示例**

| 规则 | 行为 |
|------|------|
| 可靠的 CEO | 场上有阿米娅时，按角色种类数量加数值 |

> Phase 1：实现 `rules/` 注册与触发钩子，不做真实规则池。
